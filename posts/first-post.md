# 欢迎来到我的博客

这是我的第一篇博客文章。这个博客基于 GitHub Pages 和 Giscus 构建，非常简洁。

## 博客特性

- **简洁设计**：没有复杂的现代化界面，专注于内容
- **Markdown 支持**：可以直接用 Markdown 写作
- **评论功能**：集成 Giscus 评论系统
- **GitHub Pages**：免费托管，自动部署

## 如何使用

1. 在 `posts` 目录下创建 `.md` 文件
2. 使用 YAML front matter 定义标题和日期
3. 推送到 GitHub 仓库即可自动发布
